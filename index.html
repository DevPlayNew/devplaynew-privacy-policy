자주 묻는 질문

방송은 언제 들을 수 있나요?

매일 한국 시간 기준 오전 8시, 오후 6시, 오후 11시에 새 방송이 송출됩니다. 지나간 방송은 메인 화면의 "최근 방송" 카드나 아카이브에서 다시 들을 수 있습니다.

백그라운드에서 방송이 재생되지 않아요

iOS 설정 → 별밤라디오 → "백그라운드 앱 새로 고침"이 켜져 있는지 확인해 주세요. 무음 모드(벨소리 스위치)가 켜져 있어도 미디어 음량 슬라이더로 볼륨을 조절할 수 있습니다.

사연(편지)은 어떻게 보내나요?

메인 화면의 "편지 쓰기" 버튼을 눌러 편지를 작성한 뒤 제출하면 됩니다. 편지함은 오전 6시부터 오후 6시까지 열립니다. 닉네임만 입력하면 되고, 개인을 식별할 수 있는 정보는 받지 않습니다.

내가 보낸 편지는 어디에서 확인하나요?

상단 프로필 아이콘 → "내 편지함"에서 보낸 편지와 편성 여부를 확인할 수 있습니다.

iCloud 로그인이 필요한가요?

네, 별밤라디오는 iCloud(CloudKit)로 편지와 방송 데이터를 동기화합니다. iOS 설정에서 iCloud에 로그인되어 있어야 정상적으로 동작합니다.

데이터 삭제를 원합니다

위 이메일로 "데이터 삭제 요청"이라는 제목과 함께 연락 주시면 7일 이내에 처리해 드립니다.

개인정보처리방침

1. 수집하는 개인정보

별밤라디오는 별도의 개인정보를 수집하지 않습니다. 앱 사용 시 Apple iCloud 계정을 통해 익명 식별자만 사용되며, 이름·이메일·전화번호 등 개인 식별 정보는 수집되지 않습니다.

2. 사용자 작성 콘텐츠

사용자가 작성한 편지는 익명으로 처리되며, 닉네임은 사용자가 직접 설정한 임의의 이름입니다. 편지 내용은 운영자 검수 후 승인된 것만 다른 사용자에게 노출됩니다.

3. 제3자 제공

수집된 정보를 제3자에게 판매하거나 제공하지 않습니다.

4. 데이터 저장

사용자 데이터는 Apple CloudKit(퍼블릭 데이터베이스)에 저장되며, Apple의 개인정보 보호 정책을 따릅니다.

5. 데이터 삭제

앱 내 계정 삭제 기능 또는 운영자 이메일 문의를 통해 데이터를 삭제할 수 있습니다. 요청 후 7일 이내 처리합니다.

자주 묻는 질문

앱이 수집하는 건강 데이터가 외부로 전송되나요?

혈당 기록, 식사 로그, 음식 사진은 모두 사용자의 기기 내에만 저장됩니다. 외부 서버로 자동 전송되지 않습니다.

위치 정보는 어디에 사용되나요?

주변 식당 검색 시 현재 GPS 좌표가 카카오맵 서비스로 일시 전송됩니다. 당사 서버에는 위치 정보를 저장하지 않습니다.

커뮤니티 혈당 반응 공유는 필수인가요?

아니요, 완전히 선택 사항입니다. 공유 버튼을 직접 눌러야만 익명 데이터가 업로드됩니다. 공유하지 않으면 어떤 데이터도 외부로 전송되지 않습니다.

인슐린 용량을 자동으로 계산해 주나요?

당길지도는 의료기기가 아닙니다. 인슐린 용량 자동 계산, 처방, 진단 기능은 제공하지 않습니다. 모든 영양 정보는 참고용이며, 치료·투약 결정은 반드시 담당 의료진과 상의하세요.

데이터 삭제를 원합니다

앱 내 혈당 기록 및 식사 기록은 기기에서 직접 삭제할 수 있습니다. 커뮤니티에 공유된 익명 데이터는 이메일로 삭제 요청 주시면 7일 이내 처리합니다.

개인정보처리방침

당길지도는 의료기기가 아닙니다. 앱 내 모든 정보는 참고용이며, 의료적 처방·진단을 대체하지 않습니다.

1. 수집하는 정보와 저장 위치

정보 항목수집 목적저장 위치외부 전송
GPS 위치 좌표주변 식당 검색기기 내 (임시)카카오맵 API (검색 시 일시 전송, 당사 저장 X)

이름·이메일·전화번호 등 직접 식별 가능한 개인정보는 수집하지 않습니다.

2. 제3자 서비스

  • 카카오맵 로컬 API: 주변 식당 검색 시 GPS 좌표를 카카오 서버로 전송합니다. 카카오의 개인정보처리방침이 적용됩니다.
  • Supabase: 사용자가 커뮤니티 혈당 반응 공유를 선택한 경우에 한해 익명 데이터를 저장합니다. Supabase의 개인정보처리방침이 적용됩니다.
  • 그 외 제3자에게 데이터를 판매하거나 제공하지 않습니다.

3. 건강 정보의 특별 보호

혈당 기록은 민감한 건강 정보입니다. 당길지도는 이 데이터를 기기 외부로 자동 전송하지 않으며, 광고·마케팅 목적으로 사용하지 않습니다. HealthKit 연동은 현재 지원하지 않습니다.

4. 카메라 및 사진 접근

식사 사진 첨부 기능 사용 시에만 카메라 및 사진 보관함에 접근합니다. 촬영·선택된 사진은 기기 내에만 저장되며 외부로 전송되지 않습니다.

5. 위치 정보 접근

앱 사용 중에만 위치에 접근합니다("앱 사용 중 허용"). 주변 식당 검색 시 카카오맵 API에 좌표가 일시 전송되며, 당사 서버에는 저장되지 않습니다.

6. 알림

식후 2시간 혈당 기록 알림 등을 위해 알림 권한을 요청합니다. 알림 허용 여부는 iOS 설정에서 언제든지 변경할 수 있습니다.

7. 데이터 삭제

  • 로컬 데이터: 앱 삭제 시 기기의 모든 기록이 함께 삭제됩니다.
  • 커뮤니티 공유 데이터: 이메일로 삭제 요청 주시면 7일 이내 처리합니다.

8. 의료 면책

당길지도는 의료기기법상 의료기기에 해당하지 않습니다. 혈당 예측, 인슐린 용량 계산, 처방 및 진단 기능을 제공하지 않습니다. 앱 내 모든 영양 정보는 식품의약품안전처 데이터 기반 참고용이며 실제 수치와 다를 수 있습니다. 당뇨 관련 치료·투약 결정은 반드시 담당 의료진과 상의하세요.

9. 아동 개인정보

당길지도는 만 14세 미만 아동을 대상으로 서비스를 제공하지 않으며, 고의로 아동의 개인정보를 수집하지 않습니다.
