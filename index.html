개인정보 처리방침

시행일: 2026년 5월 12일

1. 수집하는 개인정보

별밤은 별도의 개인정보를 수집하지 않습니다. 앱 사용 시 Apple iCloud 계정을 통해 익명 식별자만 사용되며, 이름·이메일·전화번호 등 개인 식별 정보는 수집되지 않습니다.

2. 사용자 작성 콘텐츠

사용자가 작성한 편지는 익명으로 처리되며, 닉네임은 사용자가 직접 설정한 임의의 이름입니다. 편지 내용은 운영자 검수 후 승인된 것만 다른 사용자에게 노출됩니다.

3. 제3자 제공

수집된 정보를 제3자에게 판매하거나 제공하지 않습니다.

4. 데이터 저장

사용자 데이터는 Apple CloudKit(퍼블릭 데이터베이스)에 저장되며, Apple의 개인정보 보호 정책을 따릅니다.

5. 데이터 삭제

앱 내 계정 삭제 기능 또는 운영자에게 문의 시 데이터를 삭제합니다.

6. 문의

앱 내 피드백 기능을 통해 연락주세요.

7. 변경 사항

본 방침은 변경될 수 있으며, 변경 시 앱 내 공지 또는 본 페이지에 게시합니다.
